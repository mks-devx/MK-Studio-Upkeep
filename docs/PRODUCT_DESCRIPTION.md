# MK Studio Upkeep

MK Studio Upkeep helps music producers and studio engineers understand the audio software installed on their Mac.

It scans plugins and DAWs locally, shows installed versions and formats, identifies executable architectures, and highlights copies worth reviewing. Hardware, audio/MIDI drivers and installed software managers have separate views. Reviewed developer links provide a direct route to downloads and support.

The app does not fetch or compare current plugin releases. It cannot prove that a plugin is obsolete, compatible with a DAW, or safe to remove based on its age. Unknown evidence stays visible as unknown.

Scanning is read-only and requires no account. Optional removal is limited to eligible bundles, uses a separate review and confirmation flow, and creates a verified local backup by default. Inventory and backup data stay on-device unless the user chooses to export and share inventory information.
