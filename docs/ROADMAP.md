# Roadmap

The current focus is a reliable local inventory and clear routes to official developer support.

- Broaden reviewed website and manager recognition using synthetic identity fixtures and official sources.
- Improve local evidence and diagnostics for incomplete metadata, related editions and scan access limitations.
- Extend accessibility, clean-account, physical Intel and macOS-version validation.
- Keep experimental removal conservative and separate from read-only scanning.

MK Studio Upkeep 0.3.0 is free and open-source under MPL-2.0, including for
professional studio use.
Automatic plugin release detection is outside the current product scope. Any future network service needs explicit consent, reliable source rights and measured coverage before it changes the interface. Windows and monitoring are future decisions rather than release commitments.
